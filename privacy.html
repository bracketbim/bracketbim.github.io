Privacy Policy

Last updated: 24 October 2026

This policy covers the bracketBIM website and bracketBIM Publisher, a private script that uploads bracketBIM's own videos to the bracketBIM YouTube channel through the YouTube Data API.

bracketBIM Publisher and YouTube API Services

bracketBIM Publisher uses YouTube API Services. By using it you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

  • Who uses it. Only the owner of the bracketBIM channel, to publish their own videos. It is not offered to other users.
  • What it accesses. With the owner's consent: uploading videos and thumbnails to the owner's channel, and reading the owner's channel name to confirm the account.
  • What it stores. The OAuth access token is stored only on the owner's computer. No YouTube data is collected, sold, shared or sent to any other server.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions; the local token is then deleted.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This website

The site is hosted on GitHub Pages and has no forms, accounts or cookies of its own. Visits to the site and to the PML Console demo (/app/) are counted with Cloudflare Web Analytics: no cookies and no tracking of individual visitors — only totals such as page views, countries and referring sites. Whatever you load into the demo stays in your browser and is never sent anywhere. GitHub may log technical data such as IP addresses — see the GitHub Privacy Statement. Fonts are loaded from Google Fonts.
