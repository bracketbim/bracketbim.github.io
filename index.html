How it works

From the model to the model. Four steps, no plug-ins.

Nothing to install and no admin rights: a read-only macro exports the trays, the browser does the work, and you paste the result back into E3D.

01

Export

One read-only macro writes your trays to a text file. The database is not changed.

knk-cwb.txt · 42 trays
02

Place

PML Console reads the routes and places every cable support by the written rules — spans, bends, slopes, branches.

240 supports · 0.4 s
03

Review

3D and 2D views with a ruler, an unfolded view of each route, and a list of what needs attention. Drag a support — the checks rerun.

0 violations
04

Build in E3D

Copy the generated PML and paste it into E3D. Each support is an EQUI with struts and brackets, marked so it can be found and rebuilt later.

PURPOSE PMLC · rebuild by route
-- step 1 macro, excerpt · Paste as Macro · only reads
alpha log /D:\exchange\knk-cwb.txt OVERWRITE
VAR !knkB COLLECT ALL CWBRAN FOR /PMLC
do !b values !knkB
  $!b
  Q REF
  Q VWIDTH
  Q POS WRT WORLD
  …

Tested, not guessed

  
Nothing is assumed about E3D. Every command is proved in a run.

  
PML had no public reference for cable work. So each command the tool writes is tried on a real E3D first, and its status — and the run that proved it — is shown next to the code.
